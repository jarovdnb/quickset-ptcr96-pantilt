How this works

Jogging here uses the same one-shot commands as the main dashboard’s calibration card, so moves are still refused by whichever profile is currently active (Advanced Settings) — not necessarily the one you're viewing/editing. To map a wider envelope from scratch, set the active profile to “none” first and watch the antenna clearance by eye, exactly like pt_keepout_record.py.

“Record boundary here” saves straight to config/keepout/<profile>.json on every click, so nothing is lost if the browser closes mid-session. Table edits (and imports) stay local until you click “Save table to profile”.
